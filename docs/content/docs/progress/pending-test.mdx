- Codex App 插件文档：新增插件安装教程，区分 AI 自动安装、手动安装和本仓库开发调试安装；同步优化插件 README 与技能说明。
- 配置与用户偏好：每个模型渠道新增 OpenAI / Gemini 调用格式选择，默认 OpenAI，切换默认格式时同步更新默认 Base URL；渠道 Tab 增加紧凑醒目的提醒，说明模型是否可选需要到“模型”Tab 选择。
- Gemini 调用格式：支持拉取 Gemini 模型列表，并用于文本问答、在线 Agent 工具调用、基础生图和图生图请求。
- 音频和视频生成：选择 Gemini 调用格式时先给出不支持提示，仍需使用 OpenAI 兼容渠道。
- 积分制 + 平台密钥（Phase 1–5，需人工验证）：
  - 后台「平台密钥」新增一个上游 Key（如 OpenAI），生图/生视频/音频/对话均走平台 Key 成功；用户端不再需要填 Key 也能生成。
  - 用户端配置弹窗已移除 API Key 输入框（BYOK 下线）；仅配置 Base URL 与模型，Key 由平台统一注入。
  - 生成成功扣积分：余额减少、流水出现 consume 记录；生成失败/取消 → refund 退款到账。
  - 余额不足：弹「积分余额不足」窗（含余额/所需/去充值），且服务端 403 兜底。
  - 免费用户每日赠送：`daily_credit_grant` 默认 3，一天一次（幂等）；新用户登录送 `signup_credit_grant`（默认 50）。
  - 定价页：顶部余额卡片 + 积分包区，下单生成 orderNo + 扫码信息；账单页：余额/流水/快捷充值。
  - 顶栏与画布顶栏余额角标显示正确。
  - 后台「积分管理」手动充/扣 + 流水查询；「对账」收入 vs 成本估算毛利；「运营配置」改 `daily_credit_grant` 等约 30s 生效。
  - 套餐系统已下线：后台无「套餐/订阅/权益」入口，仅积分包充值订单，后台确认入账只到账一次（幂等）。
  - 平台模型驱动前端 + 配置入口已删除：前端所有模型下拉（生图/视频/文本/音频/画布）选项来自后台「平台密钥」启用的模型，后台改模型后约 60s 内生效；导航栏与画布内不再有「配置」入口，用户无法自行填 Base URL / 模型 / Key（WebDAV 备份配置无 UI，保持休眠）。
  - 后台可配置积分定价：平台密钥表单新增「逐模型定价」（图片每张 / 视频每秒 / 音频每次 / 文本每次），未配置的模型按内置草案扣费；视频按每秒 × 实际时长（自动时长 -1 按 6 秒计）；改价后约 1 分钟内前端余额预检与画布成本角标与实际扣费一致。
  - Aigccc / Seedance 2.0 网关接入：后台「平台密钥」新增 Aigccc 预设（provider=aigccc），模型能力标定为 seedance-video（复用 Seedance 设置面板）；生视频走网关 `POST /api/external/v1/video/task/create`，本地参考图自动压缩后顺序上传到网关临时存储（`/api/external/v1/image/upload/batch`），视频/音频参考需公网 URL；代理按 provider=aigccc 注入 `ApiKey` 头；模式固定 pro，时长 4-15s 钳制，轮询 ≥5s 间隔。
